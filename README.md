# Microsoft AI Innovators – Sailing Crew Classification

This project was developed as part of the **Microsoft AI Innovators Summer Program**.

The goal of the project was to explore how machine learning can be used to support **sailing crew role classification and team selection** using structured sailing data.

## What I Worked On

- Developed and trained a **Multi-Layer Perceptron (MLP)** using PyTorch
- Worked on data preprocessing and preparation for model training
- Used **BCEWithLogitsLoss** for the classification task
- Evaluated model outputs and generated crew role scores
- Worked with synthetic sailing datasets and team selection logic
- Visualized crew positioning and sailing-related outputs

## Model

The classification model was implemented using **PyTorch**.

- Architecture: Multi-Layer Perceptron (MLP)
- Loss Function: BCEWithLogitsLoss
- Learning Rate: 0.001
- Batch Size: 30
- Maximum Epochs: 100
- Early Stopping Patience: 
- label-wise accuracy(avg): 0.85
